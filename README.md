# 具身智能与机器人论文知识库

这是一个可直接用 Obsidian 打开的纯 Markdown 知识库，不依赖第三方插件。

## 打开方式

1. 打开 Obsidian。
2. 选择“打开本地仓库”。
3. 选择本文件所在的 `Embodied-AI-Obsidian` 文件夹。
4. 从 [[00-首页/首页|首页]] 开始阅读。

## 目录约定

- `00-首页`：入口与阅读导航。
- `01-主题索引`：按研究方向组织的 MOC（Map of Content）。
- `02-周报`：每周精选与横向观察。
- `03-论文`：一篇论文一则永久笔记。
- `04-概念`：跨论文复用的概念卡片。
- `05-模板`：后续自动化持续使用的格式。
- `06-方法与资源`：筛选标准、阅读队列和维护规范。

## 笔记状态

- `待读`：只完成候选收集。
- `速读`：读完摘要、方法、实验与限制。
- `精读`：核查附录、代码或复现实验。

首期论文均为 2026 年 8 月的新近 arXiv 预印本。“精选”表示值得投入阅读时间，不等于论文结论已经过同行评审或独立复现。
