## 这是什么

这不是简单的论文收藏夹，而是一套围绕三个问题持续维护的研究系统：

1. 最近 7–14 天有哪些真正值得读的新论文？
2. 它们解决了什么问题，实验事实和证据强度如何？
3. 相比当前公开前沿，这项工作究竟推进了什么？

知识库采用两条并行主线：

| 主线 | 回答的问题 | 主要产物 |
|---|---|---|
| 新论文追踪 | 最近出现了什么？ | 每周精选、论文永久笔记、阅读队列 |
| SOTA 前沿坐标 | 目前最强的公开成果是什么？ | 分任务基准、实机证据、复现状态与能力缺口 |

## 内容亮点

- **证据优先**：区分作者声称、论文报告的实验事实和本库判断。
- **拒绝伪 SOTA**：只在任务、基准版本、数据、机器人本体和评测协议可比时讨论领先结果。
- **重视真实机器人**：明确区分仿真、real-to-sim 与实机证据，不用仿真高分代替真实部署结论。
- **记录失败与限制**：同时关注失败模式、合理停止、恢复能力、安全性和长期运行表现。
- **面向知识复用**：论文笔记与概念卡、主题 MOC、周报和前沿坐标相互链接。
- **顶会持续扫描**：系统整理 RSS、CoRL、ICRA、IROS 及机器学习、视觉、规划交叉顶会的相关成果。
- **纯 Markdown**：可直接作为 Obsidian Vault 打开，不依赖第三方插件。

## 快速开始

### 使用 Obsidian

1. 克隆仓库：

   ```bash
   git clone https://github.com/zhengchengjin/Embodied-AI-Obsidian.git
   ```

2. 打开 Obsidian，选择 **打开本地仓库**。
3. 选择克隆得到的 `Embodied-AI-Obsidian` 文件夹。
4. 从[知识库首页](00-首页/首页.md)开始阅读。

## 每周维护流程

1. 检索最近 7–14 天的 arXiv `cs.RO`，交叉核对 `cs.AI`、`cs.CV`、`cs.LG`。
2. 扫描 RSS、CoRL、ICRA、IROS，以及 NeurIPS、ICML、ICLR、CVPR、ICCV、ECCV、AAAI、IJCAI 等会议的官方论文列表。
3. 按问题重要性、方法增量、证据强度、可复现性和研究启发性筛选五篇论文。
4. 阅读方法、主实验、关键消融、限制、失败案例和附录实现细节。
5. 更新论文永久笔记，并判断其结果能否与当前前沿严格比较。
6. 发布周报，更新主题 MOC、概念卡、SOTA 总览和阅读队列。
7. 验证新增 wikilink，并检查最近四期是否存在重复 arXiv ID。

## 证据与状态约定

### 阅读状态

| 状态 | 含义 |
|---|---|
| `待读` | 只完成候选收集 |
| `速读` | 已阅读摘要、方法、主实验与限制 |
| `精读` | 进一步核查附录、代码或复现实验 |

### 前沿证据标签

| 标签 | 含义 |
|---|---|
| `已复核榜首` | 有官方榜单记录或独立团队按相同协议复现 |
| `作者报告榜首` | 论文报告超过可比基线，但尚无独立复现 |
| `前沿锚点` | 结果或证据很强，但缺少持续维护的公共榜单 |
| `实机强证据` | 明确报告真实机器人任务、试验次数、强基线和失败分析 |
| `仿真强基线` | 在公开仿真基准上可比，不能直接外推到真实机器人 |

## 重要说明

- “精选”表示值得投入阅读时间，不等于结论已经通过同行评审或独立复现。
- 所有“当前最强”判断都带有任务、基准、评测条件和核查日期，不做跨协议的笼统排名。
- 论文 PDF 不存入仓库；笔记链接到原文、项目页、代码和数据等一手来源。
- `.obsidian/` 本地设置被 Git 忽略，避免同步个人工作区布局和界面状态。
