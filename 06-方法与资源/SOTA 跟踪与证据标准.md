# SOTA 跟踪与证据标准

## 目标

本库同时回答两个不同问题：

1. **新颖性问题**：最近 7–14 天出现了什么值得读的新工作？
2. **领域坐标问题**：在可比条件下，目前最强的公开成果、最可靠的实机证据和仍未解决的能力缺口是什么？

周报负责新颖性，[[01-主题索引/领域前沿与 SOTA 总览|领域前沿与 SOTA 总览]]负责长期坐标。二者不能互相替代。

## SOTA 的最小记录单元

每条候选结果必须记录：

- 任务与能力，例如长程操作、跨本体泛化、触觉插入或安全停止。
- 基准名称、版本、数据划分和评测日期。
- 指标名称、绝对值、最强可比基线及差值。
- 仿真、real-to-sim 还是真实机器人；机器人本体、传感器和动作空间。
- 训练数据规模、是否使用额外数据、参数规模和测试时计算。
- 试验次数、随机种子、置信区间或方差（若作者报告）。
- 预印本/同行评审、代码、数据、检查点和独立复现状态。
- 已知失败模式、适用边界和不可比因素。

缺少基准版本、评测协议或绝对指标时，不进入“当前最强”表，只能列为“值得关注”。

## 证据标签

| 标签 | 使用条件 |
|---|---|
| 已复核榜首 | 官方榜单可追溯，或有独立团队按相同协议复现 |
| 作者报告榜首 | 论文在相同协议下超过已知基线，但尚无独立复现 |
| 前沿锚点 | 结果很强或证据维度完整，但没有完整、持续维护的公共榜单 |
| 实机强证据 | 有明确真实机器人任务、试验次数、强基线和失败分析 |
| 仿真强基线 | 在公开仿真基准上可比，但不能外推为真实机器人能力 |
| 不可横比 | 任务、本体、数据或指标差异过大，只能分别陈述 |
| 待复核 | 超过 90 天未重新检查来源或排行榜 |
| 可能过期 | 超过 180 天未核查，不再使用“目前最强”措辞 |

## 比较顺序

1. 首先比较相同基准、版本、数据划分和评测脚本。
2. 然后检查额外训练数据、模型规模、相机/触觉配置和测试时计算。
3. 仿真与实机分栏；单实验室实机与跨实验室复现分栏。
4. 成功率之外，优先补充鲁棒性、失败后停止、恢复率、长时间运行和安全事件。
5. 如果条件不能对齐，明确写“不可横比”，不要做主观排名。

## 来源优先级

1. 官方、持续维护的基准排行榜与评测仓库。
2. 同行评审论文及其官方项目页、代码和数据。
3. arXiv 预印本及作者项目页。
4. 综述仅用于发现候选，不作为榜首数值的唯一来源。

新闻稿、社交媒体演示和未公开协议的宣传数字不能单独进入 SOTA 表。

## 更新节奏

- **每周**：判断精选论文是否改变现有前沿坐标，记录代码/数据/复现状态变化。
- **每月**：重新检查活跃基准与代表性项目页，清理不可比或已失效条目。
- **每季度**：重写一次领域结论，关注评价标准是否已经从平均成功率转向 OOD、扰动、恢复、安全和长期运行。
